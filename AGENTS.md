# Rantau+

- Baca README.md untuk cara menjalankan aplikasi dan batas scaffold.
- Gunakan Flutter untuk antarmuka, Go/Gin untuk REST API, PostgreSQL untuk data, dan Node.js untuk AI Service.
- Simpan nominal dalam rupiah bulat. Hitung metrik finansial di domain Go.
- Batasi data privat dengan ID pengguna dari sesi. Gunakan migrasi berversi dan transaksi database untuk pembayaran kewajiban.
- Simpan kunci LLM di AI Service dan kunci Places di backend Go. AI meminta fungsi Go yang diizinkan dan menjelaskan hasilnya. Gunakan korpus yang sesuai untuk tiap skill.
- Jalankan pemeriksaan Go, Flutter, dan AI Service yang relevan setelah mengubah kode.
